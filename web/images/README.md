# School Crest

`thasala-crest.png` is the unmodified school crest downloaded from:
https://thasala.ac.th/images/Logo-Thasala.png

School identity reference:
https://www.thasala.ac.th/index.php?Itemid=119&id=21&option=com_content&view=article

The reference identifies grey and yellow as school colors. UI hex values are selected
for this application and are not represented as official brand color specifications.
