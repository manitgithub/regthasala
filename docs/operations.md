# โมดูล 3-8: งานหลังรับสมัคร

## 3. คุณสมบัติ เอกสาร และการชำระเงิน

- เปิดใบสมัครจากเมนูใบสมัครทั้งหมด ส่วนตรวจสอบจะแสดงตามสิทธิ์เจ้าหน้าที่
- รับสมัครตรวจเอกสารปัจจุบันทีละไฟล์ แล้วอนุมัติคุณสมบัติ ส่งกลับแก้ไข หรือไม่อนุมัติ พร้อมหมายเหตุ
- ส่งกลับหรือไม่รับเอกสาร/สลิปต้องระบุเหตุผล
- การเงินตรวจรับสลิปแยกจากผลคุณสมบัติ เมื่อผ่านทั้งสองส่วนจึงเป็นผู้มีสิทธิ์สอบ
- ใบสมัครรับนักเรียนที่ส่งกลับแก้ไขเปิดให้เจ้าของแก้ข้อมูลและส่งใหม่ได้ รูปและสลิปเก่ายังคงเป็นประวัติ ไม่ใช้เป็นไฟล์ปัจจุบัน
- ผู้สมัครแก้ไขเลขบัตร วันเกิด โครงการ หรือยอดเงินด้วยฟอร์มแก้ไขไม่ได้
- รายการที่เปิดบัตรสอบหรือประกาศผลแล้วต้องปิดการเผยแพร่ก่อนเปลี่ยนผลพิจารณา
- ฟอร์มพิจารณามี revision ป้องกันเจ้าหน้าที่ใช้หน้าข้อมูลเก่าทับการพิจารณาล่าสุด

## 4. จัดสอบ

- ตั้งห้องแยกรอบ สนาม/อาคาร ชื่อห้อง และความจุ
- ตั้งคำนำหน้า จำนวนหลัก (1-9) และเลขเริ่มต้นในหน้า “จัดสอบและห้องสอบ” เช่น `M4-` + 4 หลัก + 25 ได้ `M4-0025` เมื่อออกเลขแล้วจะล็อกการตั้งค่า โดยคงเลขเดิมทุกใบ
- ระบบออกเลขตามลำดับแยกรอบใน transaction เดียวกับการบันทึกบัตร ป้องกันเลขซ้ำและไม่ใช้เลขทิ้งเมื่อบันทึกไม่สำเร็จ ไม่รับเลขที่ส่งจากฟอร์มรายคน
- จัดเลขสอบและที่นั่งให้เฉพาะผู้ผ่านคุณสมบัติและตรวจรับเงินแล้วที่ยังไม่มีบัตร
- จัดไม่เกินความจุ หากที่นั่งไม่พอจะไม่บันทึกบางส่วน และไม่จัดทับบัตรเดิม
- เปิด/ปิดพิมพ์บัตรเป็นรอบ หรือแก้สถานที่ ห้อง ที่นั่ง และหมายเหตุรายคนที่หน้าใบสมัคร เลขสอบเป็นข้อมูลอ่านอย่างเดียว
- รายชื่อและใบเซ็นชื่อพิมพ์จากแต่ละห้อง การเข้าสอบบันทึกแยกวิชาในหน้าคะแนน
- บัตรหนึ่งใบมีห้อง/ที่นั่งเดียว ใช้กับชุดวิชาของผู้สมัคร การหมุนเวียนห้องแยกคาบยังไม่ได้รองรับ

## 5. ผลสอบ

- กำหนดคะแนนเต็มในข้อมูลรายวิชา ก่อนเริ่มบันทึกคะแนน
- บันทึกเข้าสอบ/ขาดสอบ/ยังไม่บันทึก และคะแนนไม่เกินคะแนนเต็ม แสดงครั้งละ 100 รายการ
- คะแนนผู้ขาดสอบต้องเว้นว่าง ไม่ใช้คะแนนแทนสถานะการเข้าสอบ
- เจ้าหน้าที่จัดสอบบันทึกคะแนนและผลคัดเลือก (ผ่าน/สำรอง/ไม่ผ่าน) เป็นแบบร่าง
- ผู้ดูแลหรือคณะกรรมการเปิดประกาศได้ต่อเมื่อผู้มีสิทธิ์สอบทุกคนมีสถานะเข้าสอบ คะแนน และผลคัดเลือกครบ
- การประกาศไม่จัดอันดับ ไม่ตัดสินผลให้ และไม่ใช้กติกาคะแนนเท่ากันอัตโนมัติ ต้องตัดสินตามประกาศจริงโดยเจ้าหน้าที่
- เมื่อประกาศแล้วต้องถอนประกาศก่อนแก้คะแนน ผลคัดเลือก หรือรายวิชา
- ผู้สมัครยืนยันตัวตนเพื่อดูผลของตนเองเท่านั้น ผลแบบร่างไม่แสดง

## 6. รายงาน

- สรุปจำนวนใบสมัคร ผ่านคุณสมบัติ รายการตรวจรับชำระแล้ว และรายการรอตรวจเงิน แยกรอบและโครงการ
- ยอดรายรับนับเฉพาะสลิปที่การเงินตรวจรับแล้ว ไม่ใช่ยอดเงินที่ผู้สมัครแจ้งหรือยอดทั้งหมดของใบสมัคร
- แสดงผลคัดเลือกที่บันทึกและการเข้าสอบรายวิชา แยกจำนวนคนกับจำนวนรายการวิชา
- ส่งออก CSV ภาษาไทยพร้อมป้องกันข้อความที่อาจถูกตีความเป็นสูตรในโปรแกรมตารางคำนวณ

## 7. เจ้าหน้าที่และสิทธิ์

| บทบาท | สิทธิ์หลัก |
| --- | --- |
| ผู้ดูแลระบบ | ทุกส่วน รวมบัญชีและประวัติ |
| รับสมัคร | ข้อมูลใบสมัคร คุณสมบัติ เอกสารที่ไม่ใช่สลิป |
| การเงิน | ข้อมูลใบสมัคร สลิป รายงาน |
| จัดสอบ | ตั้งค่ารอบ ห้อง ที่นั่ง บัตร คะแนนและผลคัดเลือก |
| ผู้บริหาร/คณะกรรมการ | ดูคะแนน รายงาน และเปิด/ถอนประกาศผล |

สร้าง/แก้ไขบัญชีเจ้าหน้าที่ กำหนดบทบาท ปิดใช้งาน และตั้งรหัสผ่านใหม่ได้จากเมนูผู้ใช้งาน
รหัสผ่านใหม่อย่างน้อย 12 ตัวอักษร ไม่เปิดเผยรหัสเดิม และไม่บันทึกในประวัติ
ปิดบัญชีแล้วคำขอถัดไปของเซสชันเดิมต้องยืนยันตัวตนใหม่ ไม่สามารถปิด/ลดสิทธิ์ผู้ดูแลของตนเองหรือเหลือผู้ดูแลที่ใช้งานได้เป็นศูนย์
เมนูนี้จัดการเจ้าหน้าที่ ไม่ใช่เครื่องมือแก้เลขบัตร/วันเกิดของผู้สมัคร

## 8. ประวัติ

เก็บผู้ทำรายการ วันเวลา รายการอ้างอิง และรายละเอียดการเปลี่ยนแปลงในการตั้งค่า พิจารณาใบสมัคร
แก้ไขส่งใหม่ ดาวน์โหลดเอกสาร จัดสอบ ประกาศผล ส่งออกรายงาน จัดการสิทธิ์ และเข้า/ออกระบบ
ไม่มีปุ่มแก้หรือลบประวัติผ่านเว็บ ไม่เก็บรหัสผ่าน แฮชรหัสผ่าน หรือวันเกิดในประวัติ
ไม่ได้อ้างว่าเป็นหลักฐานป้องกันการแก้ไขระดับฐานข้อมูล ผู้ดูแลเซิร์ฟเวอร์ยังต้องกำหนดสิทธิ์ฐานข้อมูล สำรองข้อมูล และนโยบายเก็บรักษาเอง
